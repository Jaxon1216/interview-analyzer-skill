# DeerFlow 项目简历要点

以下节选自 `project-interview-skill` 为 DeerFlow 生成的《面经》。这份目标简历样稿用于学习项目机制，写进个人简历时应选取自己实际参与的工作。

DeerFlow 是面向多步任务的开源智能体工作台。Next.js 聊天端连接 FastAPI 网关和 LangGraph 运行时，主代理可以在会话里分派子任务、使用沙箱生成文件；用户可以重新接入执行中的任务，在界面中查看和修改产物。

- **线程级运行准入：** 将同线程运行互斥与带键重试分开处理。默认策略拒绝对活跃线程的新运行，携带相同幂等键且输入匹配的重试复用已有记录；新运行完成准入后挂接后台任务，再检查是否仍可启动。
- **主代理组装与上下文压缩：** 按运行配置和代理策略组装工具与中间件，在模型调用前按阈值压缩旧消息，保留当前请求与近期上下文；取得可用摘要后再替换消息窗口，并将摘要带入后续模型调用。
- **流式回放与会话恢复：** 按 run 保留有限的 SSE 事件窗口，重连时根据游标续播，游标早于保留窗口则通知客户端回读线程状态并接回原运行；界面按消息身份与线程历史序号合并记录，保留分页刷新前已经可见的消息。
- **子代理委派预算：** 同时约束单次模型输出和单次运行的委派数，根据当前 run 的委派记录裁剪超额调用；执行器为每个后台任务分配独立身份，父代理用工具调用 ID 接收结果和终态，支持隔离输入或按需传入父对话快照。
- **沙箱执行租约：** 按执行持有者跟踪同一沙箱的使用关系，按用户与线程串行处理获取、绑定和释放；退出时先清理各自的命令作用域，等最后一个持有者离开且存在释放请求，再将沙箱交回提供方。
- **产物并发编辑：** 以线程写入预约和内容版本校验保护产物保存。编辑器携带打开文件时的 SHA-256，网关在可写时比对当前字节，再原子替换主机文件；线程忙和版本过期分别反馈，旧稿可留在界面处理冲突。
