## 首次发现与修正

1. **交付关联。** Q1/Q6/Q7 在“对应支柱”中混入关联 B，和映射表不一致；Q1/Q4/Q5 的学习入口混入导学或 HTML 补充链接。将直接 B 与映射表对齐，补充导航移到独立行。首次完整交付及 6 条原始错误均保留。
2. **事实范围。** 初稿把沙箱获取概括为首次工具时懒加载。修订后区分共享视图下的延迟获取与策略投影的运行前授权/获取，并收窄为首次需要沙箱的工具。初稿还把世代保护推广到全部异步提交；修订后明确只覆盖已查证的项目线程预创建等待阶段，不宣称附件上传各阶段都有同等保护。关联 bullet、课程、导学及 HTML 已同步。
3. **浏览器测试器。** 初次独立检查为 4/6：C06 的 radio 同时有顶部选择 label 和结果内的后续动作 label，合法的多 label 触发全局选择器 strict mode。限定顶部主控件后，同一份未改页面的初稿复跑 6/6。测试器同时改为枚举全部 radio 分支，并在稳定夹具中加入第三分支和次级 label 的交互回归；未更新截图基线来接受失败。
4. **准备入口。** 代码复查发现 clone 等待期间可能覆盖同名输出、断裂缓存 symlink 可能向外创建 clone。补充网络后的再次检查、排他创建输出，以及 resolve 前的断裂 symlink 拒绝；两项回归计入最终 57 项单测。

## 复跑与留存

在本仓库根目录准备开发依赖和 Chromium 后运行：

```bash
npm ci
npx playwright install chromium
npm test
npm run test:html
python3 tests/prepare_deerflow_eval.py --case e1 --output-dir .test-runs/deerflow-e1-new
```

最后一条命令在没有外部路径且缓存缺失时自动准备固定源码，然后仅生成执行输入与 manifest。仍需将 `agent-input.md` 交给独立生成者，执行生成、结构校验、实际 HTML 检查与独立内容审读；准备成功不能作为 E1 通过的证据。完整流程见[测试说明](../../tests/README.md)。

本轮全量初稿、最终课程、截图、trace、日志与本机 manifest 留在被忽略的 `.test-runs/deerflow-e1-2026-11-08-vlpvey4k/`。首次完整快照位于 `run/first-delivery/`，最终交付位于 `run/delivery/`，修订记录位于 `run/generation-notes.md`，主会话独立检查保存在 `checks/`。本摘要不包含机器绝对路径，作为重要回归的可提交记录；日常每次运行不自动产生 Git 提交。

本次只执行一轮 E1，未重跑 E2–E6 或其他语义评测套件，不能据此声称生成质量稳定提升。稳定模板使用同环境的截图基线比较；新生成页做渲染与交互验收，没有历史像素基线。没有启动 DeerFlow 业务应用、真实模型业务链路、容器或其业务测试套件。
