# DeerFlow 项目简介与简历 bullet（主 agent 补稿修订版）

> 目标简历与学习口播，供掌握后选用。基于本机完整项目范围按需只读查证；独立生成者因额度限制未交付完整输出。本稿由已知本轮诊断的主 agent 使用冻结 Skill 补充生成并编辑修订，不计作独立生成验证。

## 项目简介

DeerFlow 是基于 LangGraph 的 Agent Harness，主 Agent 通过工具与子任务执行研究、编码和文件创作，配合线程工作区、可扩展技能、上下文压缩与跨会话记忆，支持 Web 与消息渠道交互。

## 简历 bullet

- **Lead Agent 与受限子任务委派：** 主 Agent 通过 task 工具委派任务，执行器为子 Agent 新建消息状态，按配置附带上下文快照，并复用父线程工作区与沙箱。
  - 中间件限制单轮 task 调用数，并按运行内的委派账本约束累计调用数，避免拆成多轮后绕过总额；子任务在独立事件循环执行，结果或超时、取消状态作为工具消息返回主 Agent。
  - 工具调用 ID 关联消息与进度，服务端另生成执行 ID 管理后台任务登记、取消与清理，避免不同父运行中的同名调用覆盖任务登记项。
- **模型与工具中间件链：** 主 Agent 与子 Agent 复用输入净化、工具输出预算和错误处理等基础执行层，再分别组合各自的上下文处理。
  - 工具结果先净化再按预算处理；工具参数中的产物句柄先还原，再由启用的授权和写入策略检查实际参数，拒绝的调用在工具执行前返回错误。
- **Skill 渐进加载与工具授权：** 技能以含 SKILL.md 的目录包组织，默认提示提供元数据，正文由显式选择或 read_file 按需加载；会话状态保留已加载技能的轻量引用。
  - 活跃技能的 allowed-tools 同时过滤模型可见工具并拦截越权调用，权限声明参与实际执行控制。
- **上下文压缩与跨会话记忆：** 达到配置阈值后，将较早历史压成摘要并保留近期消息；摘要生成成功才替换历史，摘要、委派记录与技能引用独立保存并注入后续模型请求。
  - 过大的工具结果写入文件，以摘要和文件引用进入上下文；文件持久化不可用时退回首尾截断。
  - 启用被动记忆模式时，对话在执行结束后入队处理，入队时捕获用户身份，后台抽取持久记忆，后续会话按用户与 Agent 作用域加载。
- **线程工作区与沙箱执行租约：** 按用户和线程组织工作目录、上传文件与输出文件，父子任务复用线程沙箱；各执行者分别登记持有关系，最后一个持有者退出后才触发待处理的 provider 释放，避免一个子任务结束时关闭兄弟任务仍在使用的客户端。
  - 产物在会话状态中保存去重引用，正式内容经用户与线程授权的文件接口读取。
- **异步运行与 SSE 状态恢复：** Gateway 登记运行后通过后台异步任务驱动 Agent，SSE 连接按运行订阅事件；首次创建不自动重试，重连订阅已有运行。
  - 回放缺口触发客户端重载持久状态，再从保留事件尾部继续订阅；恢复当前视图，不保证补回所有丢失事件。
  - 创建连接断开时按取消或继续策略处理，只读订阅连接断开不会取消运行。
