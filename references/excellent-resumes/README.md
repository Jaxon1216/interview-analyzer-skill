# 优秀简历样例库（生成前对照）

**分工**：可移植规则在 [口播与简历抽象](../oral-and-resume-patterns.md)；本目录只放**项目级金样**。写简介和简历 bullet 前至少读 1 份金样的「点评」，OCR 正文用来看密度和嵌套，不是填空模板。

| 文件 | 学什么（结构） | 不要学什么（素材） |
|------|----------------|-------------------|
| [deer-flow-harness.md](deer-flow-harness.md) | 版本演进当骨架、嵌套支柱、四槽、简历可读的追问钩子 | 把该项目的产品名、层名、并发/超时数字抄到无关仓库 |
| [ai4se-agent-infra.md](ai4se-agent-infra.md) | 先背景与目标、给失败模式起能问出口的名字、流水线当交付物、指标跟在机制后面 | 编造百分比或评测集名称；把内部脚手架名单当自己的履历 |

## 加载规则

- 只复用点评里的**结构**；禁止把样例里的项目名、仓库名、内部层名、论文名、指标写进用户项目。
- 求职方向、岗位标签不改变 [海拔规则](../oral-and-resume-patterns.md)；金样里的领域词不能当成「所有项目都必须写的支柱」。
- 新增金样时：OCR 与点评放本目录；**不要**把新项目的专有名词写回 `oral-and-resume-patterns.md`。
