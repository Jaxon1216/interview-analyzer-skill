# 优秀简历样例库（生成前对照）

**分工**：可移植规则在 [口播与简历抽象](../rules/oral-and-resume-patterns.md)。写简介和简历 bullet 前默认读[酥神 bullet 模板](susu-bullet-template.md)的原文片段与表达说明，再按项目需要补读下方完整金样。读正文以对齐实际语言、密度与分层，不能只读点评后机械套槽。

| 文件 | 学什么（结构） | 不要学什么（素材） |
|------|----------------|-------------------|
| [susu-bullet-template.md](susu-bullet-template.md) | 默认表达基准：具体机制标题、直接写动作、约束融入步骤、复杂内容分层 | 迁移样例事实、身份或数字；强制每条四槽齐全 |
| [deer-flow-harness.md](deer-flow-harness.md) | 版本演进当骨架、嵌套支柱、机制与约束、简历可读的追问钩子 | 把该项目的产品名、层名、并发/超时数字抄到无关仓库 |
| [ai4se-agent-infra.md](ai4se-agent-infra.md) | 先背景与目标、给失败模式起能问出口的名字、流水线当交付物、指标跟在机制后面 | 编造百分比或评测集名称；把内部脚手架名单当自己的履历 |

## 加载规则

- 只复用表达与组织方式；禁止把样例里的项目名、仓库名、内部层名、论文名、指标写进用户项目。
- 求职方向、岗位标签不改变 [海拔规则](../rules/oral-and-resume-patterns.md)；金样里的领域词不能当成「所有项目都必须写的支柱」。
- 新增金样时：OCR 与点评放本目录；**不要**把新项目的专有名词写回 `rules/oral-and-resume-patterns.md`。
