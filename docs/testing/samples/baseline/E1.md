# 面经：DeerFlow

> 以下为目标简历与学习口播，供掌握后选用。分析范围为当前源码中 Web 任务提交、代理工具/沙箱执行、技能加载与结果展示；不含定时任务、IM 和长期记忆。

## 项目简介（简历可用）

基于 Next.js/React 与 Python FastAPI、LangGraph 的任务型 AI 对话应用，支持用户提交自然语言任务，由代理调用工具在用户线程沙箱中处理和生成文件。通过技能按需加载扩展任务流程，以流式消息、工具步骤和产物预览呈现执行结果。

## 简历 bullet

- **增量任务流与断线恢复：** 将任务运行与 SSE 观察连接分开，前端按消息片段、状态更新和自定义事件消费增量；创建请求关闭自动重试，断线通过运行标识和事件游标接续，重放缺口触发持久状态重取。
- **工具装配与执行中间件：** 按配置、模型能力和授权范围装配工具，将调用授权、沙箱审计、文件读写门禁、错误归一与输出预算放入有序中间件；在执行前约束副作用，在回程统一结果供后续模型推理。
- **线程沙箱与生命周期：** 按用户和线程绑定工作区、输入与输出目录，沙箱触达时按身份校验复用或延迟获取；执行租约追踪并发持有者，最后释放者再归还 provider，取消时排空已开始的清理工作。
- **技能发现与动态策略：** 将技能组织为目录与说明文件，默认注入元数据，延迟发现模式先给名称索引，再按需获取描述和正文。
  - 显式选择和自主读取分别形成激活来源，持久上下文保存有界引用；每次模型调用重验活跃技能并约束工具可见性与执行。
  - 显式 Agent 技能白名单生成线程文件投影，在支持隔离的沙箱中只暴露对应已启用包。
- **消息与文件交付：** 通过消息身份、可信序号和工具调用关联合并流与历史，区分处理中步骤和终态回答；文件写入输出目录后登记产物，前端通过线程文件接口取正式内容，流中写入参数提供临时预览，结束后刷新文件。
