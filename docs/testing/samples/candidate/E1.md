# 面经：DeerFlow

> 以下为目标简历与学习口播，供掌握后选用。范围为当前源码前端提交、Gateway 交互式运行、工具/沙箱、技能加载与结果展示，基线 5ecc1c2ac2de624af354bc515d5cb04f80df226c；不包含定时任务、IM 与长期记忆业务。

## 项目简介（简历可用）
基于 Next.js、FastAPI 与 LangGraph 的可扩展 AI Agent 系统，用户通过 Web 提交自然语言任务和附件，Agent 按需加载技能并调用文件与执行工具，前端流式展示处理过程与生成产物。

## 简历 bullet
- **线程运行与增量事件：** 将一次任务组织为会话内独立运行，后台执行与 SSE 订阅分离；前端分别消费消息增量、状态更新和自定义事件，断线后按运行标识恢复订阅，回放缺口时重载持久状态。
- **有序中间件与工具边界：** 将输入净化、工具输出预算、权限检查与错误规范化组合为有序执行链，模型请求和工具返回按各层约束处理；工具通过状态更新指令发布结果，使后续推理与客户端消费同一套会话状态。
- **按需沙箱与执行租约：** 工具按用户与会话身份获取执行环境，复用前重新检查执行权限与环境归属；按执行持有资源，最后一个使用者退出后交给环境提供方释放，避免并发使用者尚在执行时提前回收。
- **渐进技能加载与工具策略：** 系统提示保留技能元数据，支持可选名称索引，正文由显式选择或模型按需读取；以轻量引用记录已加载技能，并在模型可见工具与实际调用两处落实当前技能的工具声明。
- **文件产物与有界预览：** 将线程输出文件登记为规范产物引用，前端按增量合并的路径索引展示文件入口；正式内容经线程权限与路径校验读取，文本默认按字节预算预览，运行结束后刷新文件内容。


## 选材主线（导学摘录）
DeerFlow 是可扩展 Agent Harness，Web 用户提交自然语言任务后，模型借助工具读取/生成文件，客户端逐步展示消息与产物。本次按用户指定场景组织工程目标：让一次交互式任务在前端、运行管理、工具环境和文件展示之间有可追踪的状态与身份边界。这是对当前机制的分析，不是补造团队历史痛点或正式 OKR。

完整本地产物共导学、面经和 9 节核心课；验证范围及修正见上级测试记录。
