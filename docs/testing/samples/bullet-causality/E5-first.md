## 简历 bullet

- **异步报表生成：** 负责内部批量报表模块，第一版在 HTTP 请求内生成报表，长任务在验收时触发网关超时；第二版改为队列后台生成，提交请求返回受理状态，提供任务 ID 状态查询与结果下载，使调用方无需在提交请求中等待报表生成完成。

## 方案口播

我负责内部批量报表模块，做过从同步生成到异步生成的两版演进。第一版直接在 HTTP 请求内生成报表，验收时发现长任务会触发网关超时。我当时比较过延长网关超时和改成队列两种方案，第二版采用了队列。两者的关键区别是，延长超时仍然需要请求等待报表生成；队列则把任务受理和后台执行拆开，相应地需要提供后续的状态查询和结果获取方式。

第二版中，提交请求返回受理状态，报表通过队列在后台生成，调用方通过任务 ID 查询状态，生成完成后下载结果。验收确认了请求返回受理状态、报表在后台生成这两项行为。这里受理成功和生成完成是两个阶段，调用方拿到受理响应后，还需要查询任务状态再获取产物。
