## 项目简介
面向运营的批量导出服务，通过任务队列执行导出，以同一任务 ID 关联状态查询与结果下载，让处理过程和生成结果可对应追踪。

## 简历 bullet
- **批量导出任务链路：** 以任务 ID 串联队列处理、状态查询与结果下载，调用方沿同一任务查看处理状态并获取导出结果。
