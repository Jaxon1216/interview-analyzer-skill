## v1.2.0：大酥化时代来临

🎉 `project-interview-skill v1.2.0` 上线

**大酥化时代来临。**

给 `asu-skill` 提过 PR，也被成功 merge；现在轮到你的项目被认真读一遍。

秋招在即，别只会写“参与过某某项目”。用这个 Skill 扫描真实代码库，把项目炼化成：

- 能放进简历的 bullet
- 能扛住追问的 STAR 口播
- 能按顺序补齐的学习路径

本次核心能力：

- 项目全链路扫描，提炼真实技术支柱
- 简历 bullet 与面试主问、追问自动关联
- 第一人称 STAR 口播，减少“简历会写、项目不会讲”
- 内部名词和实现细节表达护栏，外部面试官也能听懂
- 前后端参考样例，校准输出深度
- DeerFlow 示例生成效果展示：简历 bullet、面经和学习顺序一套打通

前后端项目都能用。npm 一条命令安装：

```bash
npx project-interview-skill install
```

然后在项目里对 Agent 说：

```text
/project-interview-skill 我的背景是 xx，我想找 xxx 岗，请基于这个项目生成导学和面经。
```
