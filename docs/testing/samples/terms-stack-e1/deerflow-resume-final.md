# 面经：DeerFlow

目标简历与学习口播，供掌握后选用；本次分析覆盖 Web 发起任务、Gateway/Agent 执行、工具与沙箱、技能加载和结果展示，不包含定时任务、IM、长期记忆。

## 项目简介

DeerFlow 是基于 Next.js 和 LangGraph 的 AI 任务工作台，用户通过聊天提交需求与附件，Agent 按需读取技能并调用工具完成分析、文件处理等任务，页面流式展示执行过程、回答与输出产物。

### 技术栈

前端：TypeScript、Next.js 16、React 19、LangGraph SDK、TanStack Query、Streamdown 2.5；后端：Python 3.12+、FastAPI、Pydantic、LangChain 1.3+ / LangGraph 1.2 系列、asyncio；执行与通信：本地/可选远端沙箱、MCP、HTTP/SSE、Nginx；状态存储：LangGraph checkpoint（内存/SQLite/PostgreSQL），事件缓冲与重放（内存/Redis）。

## 简历 bullet

- **异步运行与准入控制：** 面向长耗时 AI 任务，将会话与单次执行分离，FastAPI 校验输入后由统一准入层控制同会话活动运行，并以显式幂等键复用重复受理；执行交给后台 asyncio task，创建连接、只读观察与取消分别处理，任务进度和终态由独立运行记录表达。
- **Agent 中间件链：** 基于 LangChain 与 LangGraph 组装模型、内建/MCP 工具和有序中间件，将输入处理、运行时授权、工具错误转换及结果预算放在模型与工具边界；模型可以围绕 ToolMessage 继续决策，能力扩展和执行限制在各自钩子生效，避免只依赖提示词约束工具行为。
- **沙箱资源租约与路径作用域：** 为兼顾按需执行和同会话并发复用，默认共享视图走惰性初始化，工具首次需要沙箱时获取，按执行持有租约，最后持有者退出才交回 provider，并在取消与执行收尾时清理；文件工具通过用户/会话范围的虚拟路径访问工作区、上传和输出目录，区分逻辑映射与实际执行环境的隔离能力。
- **技能渐进加载与工具策略：** 技能以 SKILL.md 包组织，系统提示默认只给元信息、正文与资源按需读取，可选名称索引加元信息查询进一步延迟发现；仅在可信加载或显式命令激活后应用 allowed-tools，显式激活在本轮优先，避免启用目录或读取其他技能就扩大指定工作流的工具权限。
- **SSE 增量同步与产物交付：** 为持续呈现长任务，消息 chunk 交给 LangGraph SDK 组装，非消息状态按 reducer 合并，自定义事件承载执行进度；通过 SSE 游标重放、收到 gap 时重读持久状态恢复观察，产物经会话范围接口与路径编码独立读取，使过程、回答和文件各有明确的数据来源。
