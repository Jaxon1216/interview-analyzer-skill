## 面试问题

### Q1 同一任务与多次尝试

- 对应支柱：B1
- 触发依据：同一任务 ID
- 考查目标：任务身份与尝试次数的区别
- 学习入口：[C03](../guide-backend/03-任务状态.md)

**面试官问题**：重试为什么不创建新任务？

**口播版**：一次任务可以有多次尝试。这里循环复用同一个 Task 对象和 id，attempts 记录次数；保留身份不代表副作用幂等，也不保证重启后恢复。
