# EdgeMetric 项目简介与简历 bullet

> 以下为基于合成材料的目标简历表述，供掌握后选用。

## 项目简介

EdgeMetric 是运行在单机边缘设备上的嵌入式时间序列存储，支持按序列和时间范围写入、查询及删除。以日志、内存有序表和有序不可变文件组织数据，支持启动恢复、快照查询与后台文件合并。

## 简历 bullet

- **单写入者与 WAL 恢复：** 写入请求进入单写入者队列，日志记录长度、校验和与递增序号；追加并 fsync 成功后才确认写入，再更新内存有序表；启动时重放日志，遇到不完整或校验失败的尾记录即停止。
- **内存表轮转与刷盘提交：** 内存表达到配置上限后冻结，新写入进入新表；后台将冻结表写成有序不可变文件，原子替换 manifest 后才回收对应日志。
- **MVCC 快照与安全回收：** 查询开始时固定可见序号与文件集合。
  - 合并内存表与文件记录，同一键取可见序号内的最新值，删除标记遮蔽较旧值。
  - 后台合并文件时保留活跃查询仍可能看到的版本；旧文件待查询引用释放后才删除。
- **文件级查询裁剪：** 利用文件的序列目录与时间范围跳过不相关文件，候选记录仍需扫描。
