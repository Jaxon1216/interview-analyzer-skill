依据：仅阅读本 review 目录中的 cases.json、deerflow-facts.md、A/B 的 output.md 与 terminology-notes.md。未查实现代码或版本映射；本次问题可由给定材料判断，无需外部查询。pass 表示满足本例要求，轻微表达偏好不影响判定；不以英文数量或固定字符串打分。

## 总评

A/B 的 T1–T5 均通过，体现了中文更自然时保留中文、领域通用概念有机制支撑时保留英文。T6 各有一处需要修改：A 避免将 worker 过度具体化为进程，B 避免仅凭“常见”保留没有额外表达优势的 Middleware。两组都没有虚构个人职责、历史升级或量化收益，也没有把可搜索私有符号当成行业通用架构。不据此推断总体优劣或同行普及率。
